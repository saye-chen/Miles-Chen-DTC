# Public 资源管理规则

## 目录职责

- `public/` 只保存运行时会被网站加载的资源，以及经过登记的原始素材库。
- 优化后的网页资源放在 `public/images/journey/` 根目录：PNG 作为高质量母版，WebP/AVIF 作为浏览器交付格式，`-768` 作为小屏版本。
- 原始下载图、摄影母版和后续可重新裁切的源文件统一放在 `public/images/journey/originals/`，不得散落在运行资源根目录。
- `public/images/journey/README.md` 登记运行资源；`public/images/journey/originals/README.md` 登记原始素材与来源。

## 新增资源流程

1. 先用 `rg` 检索现有引用，确认是否已有可复用资源。
2. 新资源先放入 `originals/`，确认构图和用途后再生成网页交付版本。
3. 页面只引用优化版本，不直接引用下载源文件。
4. 在对应 README 登记用途、来源、授权状态和是否为演示素材。
5. 删除未引用的旧版本、备用图、重复格式和系统文件。
6. 运行 `pnpm build`；涉及交互或响应式裁切时补充浏览器截图/Playwright 验证。

## 清理规则

- 不保留没有代码引用、没有原始素材价值、也没有明确设计用途的图片。
- 不把临时下载文件、处理脚本产物、`.DS_Store` 或未登记的备份放进 `public/`。
- 外部图片必须保留来源页面和授权待确认记录；正式商业发布前重新核对许可和肖像权。
