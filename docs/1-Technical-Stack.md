## 三、版本与依赖规则

- 使用 `pnpm-lock.yaml` 锁定依赖，默认不混用 npm、Yarn 或 Bun。
- 核心依赖升级前先检查兼容性并运行构建。
- `node_modules/`、`.nuxt/`、`.output/` 等生成目录不提交 Git。
- 未确定支付、库存、CMS、数据库或登录方案前，不提前安装对应依赖。
- 新增依赖必须说明使用场景和对构建体积的影响。
