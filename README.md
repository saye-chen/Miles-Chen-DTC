# Miles-Chen-DTC

Miles Chen 独立站前端项目，当前处于基础环境与品牌官网原型筹备阶段。

技术选型与开发约束见：[技术选型](docs/1-Technical-Stack.md) · [开发规范](docs/2-Development-Standards.md)

## 当前状态

- Nuxt 3 项目已创建，默认页面尚未替换为正式品牌首页。
- 当前先验证品牌视觉方向、页面结构和交互体验。
- 产品、品牌名称、目标国家、支付、物流和后台系统尚未最终确定。

## 环境要求

- Node.js 24.18.0 LTS
- pnpm 11.x（当前本机为 11.19.0）
- VS Code + Vue - Official 扩展

## 常用命令

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

开发服务器默认地址：[http://localhost:3000](http://localhost:3000)
